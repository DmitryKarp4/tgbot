# Вступление  
Этот бот является простым телеграм-ботом, который проверит ваш пароль по списку rockyou.txt и с помощью сайта HaveIBeenPwned

## Установка  
### Регистрация бота  
Необходимо написать боту @BotFather команды /start, затем команду /newbot и выполнить дальнейшие его требования.  
При успешной регистрации вы получите HTTP API бота, его нельзя разглашать и потерять. Он используется для контроля бота.  
### Установка бота  
Клонировав репозиторий вам необходимо заменить в шестой строке "YOUR-API" на ваш API.  
Распакуйте rockyou.txt.zip и переименуйте его в rockyou.txt.  
Теперь необходимо скачать нужные библиотеки. Нужно запустить коммандную строку от имени администратора и прописать следующую команду:  
` pip install pyTelegramBotAPI requests `  
Всё что осталось - запустить код и написать боту.  

## Техническая информация  
Логи записываются в logs.txt  
Список популярных паролей находится в rockyou.txt
